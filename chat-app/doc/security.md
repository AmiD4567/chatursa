# Меры безопасности чат-приложения

## 1. Защита регистрации (rate limiting)

**Файл:** `backend/server.js`

- **Ограничение регистраций:** не более 3 регистраций с одного IP за 60 минут
- **Ограничение входов:** не более 10 попыток входа с одного IP за 15 минут
- Механизм: in-memory хранилище (сбрасывается при перезапуске backend)
- Используется `express-rate-limit`

## 2. Сложность пароля

**Файл:** `frontend/src/App.js`

- Минимальная длина: 8 символов
- Обязательно: минимум 1 заглавная буква, 1 цифра, 1 спецсимвол
- Валидация на клиенте перед отправкой формы
- Проверка на сервере дублируется

## 3. Base64 для учётных данных в localStorage

**Файл:** `frontend/src/App.js`

- Пароль кодируется в Base64 перед сохранением в `chat_credentials`
- Флаг `_enc: true` указывает на закодированный пароль
- Обратная совместимость: пароли без флага `_enc` читаются как есть
- Декодирование происходит при автоматическом входе

## 4. Cross-Origin Resource Policy (CORP)

**Файл:** `backend/server.js`

- Явно установлен заголовок `Cross-Origin-Resource-Policy: cross-origin` для всех ответов
- Позволяет браузеру загружать статические ресурсы (изображения, стикеры) с другого origin
- Без этого заголовка Chrome блокирует cross-origin загрузку ресурсов

## 5. CORS

**Файл:** `backend/server.js`

- `app.use(cors())` — разрешены кросс-доменные запросы с любого origin
- Без этого фронтенд на `localhost:3000` не смог бы общаться с backend на `192.168.210.48:3001`

## 6. MIME-тип .avif

**Файл:** `backend/server.js`

```js
express.static.mime.define({ 'image/avif': ['avif'] });
```

- Явно зарегистрирован MIME-тип для `.avif` файлов (стикеры)
- Без этого сервер возвращал `application/octet-stream`, и браузер не мог корректно отобразить AVIF-изображения
