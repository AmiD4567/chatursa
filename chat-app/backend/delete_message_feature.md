# Реализация функции удаления сообщений через правую кнопку мыши

## Что было реализовано в сервере:

1. Добавлен обработчик `socket.on('delete_message', ...)` в файле server.js
2. Проверка, что пользователь является автором сообщения (или администратором)
3. Удаление сообщения из базы данных
4. Удаление всех реакций на это сообщение
5. Отправка события `message_deleted` всем участникам чата

## Как должно работать в клиенте:

1. В интерфейсе чата должно быть реализовано отображение правой кнопки мыши при нажатии на сообщение
2. При выборе "Удалить" должен отправляться socket-событие:
   ```javascript
   socket.emit('delete_message', { messageId: 'uuid' });
   ```

## Функциональные особенности:

1. **Проверка прав**: Только автор сообщения или администратор может удалить сообщение
2. **Удаление реакций**: Все реакции на удаленное сообщение также удаляются
3. **Синхронизация**: Уведомление об удалении отправляется всем участникам чата
4. **Логирование**: Все действия логируются в консоль сервера

## Дополнительные возможности (для будущего развития):

1. Добавить проверку роли пользователя (администратор)
2. Реализовать удаление сообщений других пользователей администраторами
3. Добавить подтверждение удаления
4. Добавить возможность восстановления удаленного сообщения

## Технические детали:

- Сообщение удаляется из таблицы `messages`
- Реакции удаляются из таблицы `message_reactions` 
- Используются транзакции для обеспечения целостности данных
