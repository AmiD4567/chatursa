## Фазы внедрения

### Фаза 1 — Надёжность (≈ неделя)
1. Завершить FCM-пуши: сервер → fcm_tokens → показ при убитом приложении.
2. Аудит E2EE-совместимости (если на десктопе включено — мобайл обязан читать).
3. Оффлайн-очередь отправки (аналог outbox).

### Фаза 2 — Коммуникационный паритет (≈ 1–2 недели)
4. Ответы (reply) + реакции, если отсутствуют.
5. Пагинация истории через существующий сокет-эндпоинт `get_messages_before`.
6. Пересылка (одиночная → затем мульти).

### Фаза 3 — Догоняющие фичи (по потребности)
7. Треды, опросы, пины.
8. Поиск файлов, задача из сообщения.
9. Тёмная тема / оформление.

## Принципы
- Серверные API переиспользуем как есть — мобильные фичи в первую очередь
  клиентская работа.
- Каждая фаза заканчивается релизом APK (теги vN-apk) и прогоном матрицы.
