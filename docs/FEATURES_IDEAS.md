# Идеи фич для ChatUrsa — вовлечение всех отделов

## Социальные механики (вовлечение)

### 1. Kudos / Спасибо / Доска почёта
- Любой сотрудник может отправить публичное «спасибо» коллеге
- Формат: `@Имя Благодарность` с комментарием
- В конце месяца/недели — топ благодарностей
- Система баллов/рейтинга: кто больше всех помог, того объявляют «Сотрудник месяца»
- Привязать к призу (мерч, отгул, пицца)
- Технически: отдельный чат-канал "Спасибо" или модальное окно

### 2. Случайный кофе (Random Coffee)
- Раз в неделю бот сводит двух случайных сотрудников из разных отделов
- Создаётся прямой чат с сообщением: «Выпейте кофе, познакомьтесь!»
- Можно добавить тему для разговора (интересный факт, вопрос недели)
- Участники могут нажать «Встретились» / «Не смогли»
- Статистика: сколько знакомств состоялось
- Мощно разрушает барьеры между отделами

### 3. Дни рождения + Сбор на подарок
- Автоматическое утреннее поздравление в общем чате
- Кнопка «Скинуться 🎁» — сбор денег среди желающих
- Анонимные суммы: кто сколько хочет
- Именинник видит только общую сумму, не кто скинулся
- Возможность прикрепить открытку / гифку

### 4. Кастомные стикеры / реакции
- Набор корпоративных стикеров: маскоты, фото с производства, лица (с разрешения)
- Загружаются админом, доступны всем
- Люди общаются стикерами — вирусное вовлечение
- Кастомные реакции под сообщениями (не только ❤️, но и корпоративные)

### 5. Коллега месяца / Голосование
- Раз в месяц — голосование: кто помог больше всех
- Номинируют на основе благодарностей
- Активно: каждый может проголосовать за номинанта
- Победитель: мерч, пицца, отгул, запись в «Зал славы»

### 6. Чаты-каналы "Курилка"
- По интересам: #рыбалка, #авто, #книги, #мемы, #игры, #спорт, #кулинария, #дача, #путешествия
- Создаются по заявке от сотрудников
- Люди сидят в чате из-за общения, а не работы
- Каналы видны всем, вступить может любой

### 7. Ачивки / Достижения (Gamification)
- "Ранняя пташка" — первое сообщение дня (5 раз)
- "Душа компании" — 50 благодарностей от коллег
- "Мастер чата" — 1000 сообщений
- "Помогатор" — помощь 10 разным коллегам
- Ачивки видны в профиле, можно похвастаться

### 8. Онлайн-статус "На обеде" / "В переговорной"
- Кастомные статусы: "На обеде 🍽️", "В переговорной до 15:00", "В командировке", "Удалённо 🏠"
- Видны всем, созданы для контекста
- Можно выбрать из списка или написать свой
- Авто-сброс через N часов

### 9. "Где пообедать сегодня?" (опрос-голосовалка)
- Бот в 11:00 предлагает варианты (столовая, доставка А, доставка Б)
- Голосование, результат в 11:45
- Можно добавить бронирование столиков в столовой

### 10. Поздравления с праздниками
- Автоматические поздравления с профессиональными праздниками
- С Днём бухгалтера, Днём программиста, Днём рождения компании и т.д.
- Генерация картинки-поздравления с логотипом

## Личная продуктивность (удержание)

### 11. Календарь-напоминалка по жизни
- Личные дела: запись к врачу (ДМС), день рождения ребёнка, коммуналку оплатить
- Разовые и повторяющиеся напоминания
- Чат как личный органайзер
- = люди заходят каждый день, потому что там их напоминалки

### 12. Чат-бот "Спроси у коллег"
- Быстрый опрос в своём отделе или среди всех
- «Кто сегодня в столовой обедает?»
- «Кому нужен кофе перед планеркой?»
- «Кто едет на корпоратив своим ходом?»
- Одной кнопкой, без создания полноценного опроса

### 13. Заметки / список задач (личный ToDo)
- Простой список дел прямо в чате
- Можно написать себе: `/todo купить молоко`
- Приходит напоминание в указанное время
- Синхронизация между устройствами

### 14. Корпоративная база контактов
- Найти сотрудника не только по ФИО, но и по: должности, отделу, номеру телефона, email, дню рождения
- Быстрый набор / позвонить (с мобильного)
- При нажатии на номер — сразу звонок через VoIP/мобильный

### 15. Чаты с ботом-помощником
- "Какая сегодня погода?"
- "Когда ближайший праздник?"
- "Напомни в 14:00 про планерку"
- "Покажи расписание обедов"
- Простые бытовые вопросы без поиска в интернете

## Рабочие инструменты (польза для работы)

### 16. Заявки в IT
- Проблема с компом, принтером, доступом → автоматически системным администраторам
- Форма: тема, описание, срочность (низкая/средняя/критичная), прикрепить скриншот
- IT-отдел видит очередь, меняет статус (принято / в работе / выполнено)
- Уведомление автору: «Ваша заявка выполнена»
- Категории: доступы, ПО, железо, сеть, принтеры, прочее

### 17. Заявки в Инженерную службу
- Протечка, нет света, сломался станок, дверь не закрывается и т.д.
- Направляется электрикам/сантехникам/КИПиА/механикам
- Адрес / номер кабинета / цеха
- Фото — обязательно
- Статусы: принято → назначен → в работе → выполнено

### 18. Заявки на пропуска
- Бюро пропусков + СБ: запрос пропуска для посетителя/подрядчика
- Поля: ФИО посетителя, организация, дата/время, цель визита, ответственный сотрудник
- Авто-согласование с ответственным
- Готовый пропуск → PDF с QR-кодом

### 19. Поручения руководства
- Генеральный / Исполнительный / Финансовый директор ставит задачу
- Кому, что сделать, дедлайн
- Контроль исполнения: исполнитель отмечает "Готово"
- Руководитель подтверждает или отклоняет
- Просроченные задачи подсвечиваются красным
- **Напоминания**: за день, за час, в момент дедлайна
- История всех поручений по сотруднику

### 20. Заявки на ТМЦ (снабжение)
- Любой отдел запрашивает материалы/инструменты/канцтовары
- Согласование с руководителем отдела → снабжение → склад
- Статусы: черновик → согласование → закупка → на складе → выдано
- Можно прикрепить фото/артикул

### 21. Сменные рапорты (производство)
- Мастер смены заполняет: что произвели (номенклатура, кг/шт)
- Сырьё (сколько израсходовано)
- Брак (причина, количество)
- Остановки (причина, время)
- Начальник фабрики видит сводку за день/неделю/месяц
- История по сменам, статистика

### 22. Реестр договоров (юр/договорной отдел)
- Контрагент, номер договора, дата начала, дата окончания, сумма
- Статус: действует / расторгнут / на согласовании
- Уведомление об истечении за 30 / 14 / 7 дней
- Прикрепить скан договора + дополнилок

### 23. Заявки клиентов (отдел сбыта)
- Менеджер вносит заказ: клиент, товар, количество, дата отгрузки
- Производство получает задание
- Склад подтверждает отгрузку
- Клиенту (вне системы) — не надо, внутренний процесс

### 24. Протоколы испытаний (лаборатория)
- Результаты анализов сырья / готовой продукции / воды / смывов
- Доступны производству, ФФЦ, ОТК
- Норма / факт / заключение (годен / не годен)
- История по партиям

## Для руководства (контроль)

### 25. Дашборд предприятия
- Ключевые показатели: текущие заявки, просроченные поручения
- Согласования на паузе (кто не ответил)
- Сводка по сбыту (за день/неделю/месяц)
- Активные инциденты (IT, инженерная)
- Дни рождения сотрудников на сегодня/неделю

### 26. График дежурств (охрана, КПП, проходная)
- Кто, когда, на каком посту
- Смена (день/ночь), время начала/конца
- Подмена (просьба подменить)
- Все видят свой график

### 27. Наряды-допуски (охрана труда + инженерная)
- На опасные работы (высотные, электро-, газоопасные)
- Согласование: мастер → инженер по ОТ → механик/энергетик
- Срок действия, состав бригады, СИЗ
- Фото/скан наряда

### 28. Календарь бухгалтера (дедлайны)
- Сдача отчётности: НДС, налог на прибыль, РСВ, СЗВ, 6-НДФЛ
- Уведомления за неделю, за 3 дня, за день
- Повторяющиеся события

## Технические / инфраструктурные

### 29. Легковесная CRM (воронка продаж)
- Этапы: лид → переговоры → счёт → оплата → отгрузка → закрыто
- Drag-n-drop по статусам
- Карточка клиента: контакты, история, документы
- Привязка к договорам и отгрузкам

### 30. База контрагентов
- Поиск по названию / ИНН / телефону / email
- История взаимодействий (кто, когда, по какому вопросу)
- Привязка к договорам и заявкам

### 31. Запрос документов у сотрудников (кадры / бухгалтерия)
- Кадровик/бухгалтер запрашивает: копия паспорта, ИНН, СНИЛС, диплом
- Массовая рассылка: выбранному отделу или всем
- Сотрудник прикрепляет скан/фото и отправляет
- Статус: запрошено → получено → проверено

### 32. Расчётные листки (HR → сотрудникам)
- Автоматическая рассылка PDF расчётных листков зарплаты
- В личный чат сотрудника 2 раза в месяц
- Защита паролем или просмотр только в приложении (персональные данные)

### 33. Календарь мероприятий
- Выставки, конференции, вебинары, тренинги
- Дата, место, программа, участники, бюджет
- После мероприятия — отчёт / фото / результаты

### 34. Журнал происшествий (СБ)
- Смена охраны фиксирует события: нарушитель, авария, проверка МЧС
- Дата, время, место, описание, принятые меры
- Начальник СБ видит сводку за период

### 35. Планировщик отпусков (тепловая карта)
- Кто на какой неделе в отпуске
- Визуальная календарная сетка (на месяц/квартал)
- Не пересекать ключевых сотрудников
- Утверждение начальником отдела

### 36. Ежедневный дайджест
- В 9:00 приходит сводка: дни рождения, задачи на сегодня, мероприятия
- Персонализированный под пользователя
- Количество непрочитанных уведомлений / задач

### 37. Микроблог руководства
- Генеральный директор пишет пост (как в Telegram-канале)
- Все видят, могут ставить реакции
- Для объявлений, мотивационных писем, итогов недели

### 38. Опросы по отделам (узкие)
- Быстрое голосование внутри отдела: «Кто заказывает пиццу в пятницу?»
- «Удобно ли всем в 10:00 провести планерку?»
- Анонимные: «Оцените психологический климат в отделе»

### 39. Совместное редактирование документов в чате
- Встроенный простой редактор текста (без гуглодоков)
- Несколько человек правят заметку/протокол встречи
- Авто-сохранение, история изменений

### 40. База знаний не только wiki, но и FAQ
- Часто задаваемые вопросы: "Как оформить пропуск?", "Где взять ключ от серверной?"
- Голосование "Было полезно 👍" / "Не помогло 👎"
- Поиск по ключевым словам

## Блок 2 — Неочевидные идеи (продолжение)

### 41. Внутренняя "Авито" / Доска объявлений
- Продать/отдать/купить: мебель, техника, детские вещи, запчасти
- Категории, фото, цена (или "бесплатно"), контакт
- Очень востребовано на любом крупном предприятии
- Чат-бот делает рассылку по подписке на категории

### 42. Подписка на обеды / столовая
- Сотрудник выбирает комплексный обед на завтра до 10:00
- Столовая видит количество порций, готовит без излишков
- Оплата с карты/удержание из зарплаты
- Можно отменить за час
- Актуально для производства со столовой

### 43. Корпоративный такси / трансфер
- Заявка на такси: откуда, куда, во сколько, количество мест
- Для командировок, разъездных сотрудников, поздних смен
- Согласование с руководителем (если нужно)
- Приходит уведомление водителю/диспетчеру

### 44. Конференц-залы / Переговорные (бронирование)
- Видеть занятость комнат на день/неделю
- Забронировать на N часов (сейчас вроде есть, но проверить)
- Уведомление за 5 минут: "У вас переговорная в 14:00"
- Отмена брони при неявке (15 мин авто-отмена)
- Интеграция с календарём

### 45. E-invoice / Электронные счета (договорной отдел)
- Создание счёта на оплату внутри чата
- Заполнить: контрагент, сумма, назначение
- Скачать PDF-файл готового счёта
- Отправить контрагенту через чат (экспорт)

### 46. Тренинги / Обучение (видеокурсы + тесты)
- Каждый месяц новый курс: пожарная безопасность, охрана труда
- Видео (ссылка на YouTube/Rutube) + тест в чате
- Отметка о прохождении, статистика по отделам
- Для ОТ и ГОиЧС — обязательные инструктажи с подписью

### 47. Создание/закрытие смен (магазин, эстакада)
- Начало смены: "Чек-лист открытия" (холодильники работают, касса, учёт)
- Конец смены: "Чек-лист закрытия" (выручка, остатки, проблемы)
- История по сменам, подпись ответственного
- Для магазина мороженого, эстакад, КПП

### 48. "Где ключи?" / "Где инструмент?" (учёт выдачи)
- Учёт выдачи ключей от кабинетов/цехов/серверных
- Кто взял, когда, на сколько, когда вернул
- Авто-напоминание, если не вернул вовремя
- То же для инструмента (драйвер, станок, прибор)

### 49. Голосовой чат / Walkie-talkie
- PTT (push-to-talk) как рация
- Для склада, производства, КПП — где руки заняты
- Внутри отдельного канала/группы
- Проще чем звонить, быстрее чем писать

### 50. Бесплатный WiFi через чат (для гостей/подрядчиков)
- Гость заходит в чат → пишет боту "wifi"
- Бот выдаёт одноразовый пароль на N часов
- Аудит: кто, когда, с какого устройства подключался
- СБ контролирует доступ

### 51. QR-коды на оборудование / кабинеты
- На каждом станке/принтере/двери кабинета QR-код
- Навёл камеру → открылся чат с объектом
- Можно: оставить заявку (сломался), посмотреть историю, кто ответственный
- Для IT (принтеры), инженерной (насосы, компрессоры)
- Уникальная фича, мало где есть

### 52. Цифровой аналог "Доски почёта" (физ. стенд)
- Витрина лучших сотрудников месяца
- Фото, должность, достижение
- Выводится на экран в столовой/проходной (веб-страница)
- Синхронизация с Kudos / Коллега месяца

### 53. Бронирование корпоративного мерча
- Каталог: футболки, кружки, блокноты, ручки с логотипом
- Выбрать размер, цвет, количество
- Заявка → склад выдаёт
- Для новичков и сотрудников (на день рождения / выслугу лет)

### 54. Генератор поздравительных открыток
- Выбрать шаблон, вставить имя получателя
- Отправить в чат коллеге или группу
- С логотипом компании, корпоративным стилем
- Без дизайнера, за 10 секунд

### 55. Трекер привычек / ЗОЖ
- "Выпил воды 💧" (8 раз в день)
- "Сделал зарядку 🏋️"
- "Прошёл 10000 шагов 🚶"
- Корпоративный челлендж: кто больше
- Рейтинг отдела, приз победителю в конце месяца
- Для HR и корпоративной культуры

### 56. Автоподпись к сообщению
- Каждый сотрудник настраивает подпись (должность, отдел, телефон)
- Автоматически добавляется к каждому сообщению
- "Иванов Иван, Отдел снабжения, доб. 123"
- Полезно в кросс-отдельной коммуникации: сразу понятно кто пишет

### 57. "Чья очередь мыть посуду / поливать цветы?"
- График дежурств по кухне, цветам, общим зонам
- Создаётся административно или голосованием
- Напоминание дежурному с утра
- Кто не сделал — все видят

### 58. Сообщение "Я на месте" (визитка на день)
- Утром нажать кнопку "Я на работе" / "Удалённо" / "В командировке"
- Все видят, кто где сегодня
- Замена письменным отчётам о присутствии
- Для руководителя: кого нет на месте

### 59. Карта территории / Цеха
- Интерактивная схема предприятия
- Найти кабинет буквально: "где находится отдел кадров?"
- Найти человека: кто сидит в кабинете 304
- Поиск по фамилии → показать на карте

### 60. Сбор идей / Рацпредложения
- "Что улучшить на производстве / в офисе?"
- Подача идеи анонимно или открыто
- Голосование "Нравится 👍" / "Не нравится 👎"
- Руководство отмечает "Взяли в работу" / "Отклонено"
- Лучшая идея месяца — премия

### 61. Чат с кабинетами (по комнатам)
- Чат для каждого физического кабинета/цеха
- "12 кабинет": пишут только те, кто там сидит
- "Цех ФФЦ": сообщения для работников цеха
- Авто-участие в чате своего кабинета/цеха
- При смене кабинета — переподписка

### 62. Калькулятор отпускных / больничных
- Ввести даты → примерная сумма начислений
- Интеграция с HR-заявками (из заявки → сразу сумма)
- Для информации, без расчётных документов
- Полезно: сотрудники постоянно это спрашивают у бухгалтерии

### 63. Фотодоска смены (производство)
- В конце смены мастер прикрепляет 1-2 фото цеха
- "Всё чисто, оборудование работает"
- Для начальства: визуальный контроль без выхода из кабинета
- История фото по дням/сменам

### 64. "Кто сегодня в офисе?" (виджет)
- Быстрый взгляд: кто на месте, кто удалённо, кто в отпуске
- Аватарки с цветным индикатором
- Для планирования встреч/совещаний
- На главной странице портала

### 65. Комплимент дня (автоматический)
- Каждое утро случайному сотруднику приходит: "Вы классный! 😊"
- Выбор из пула тёплых фраз
- Анонимно, но можно раскрыться
- Поднимает настроение на весь день

### 66. Корпоративная книга рецептов
- Сотрудники делятся рецептами (с фото)
- Оценивать, комментировать
- Категории: салаты, супы, выпечка, десерты
- Для столовой: что готовить по запросам

### 67. Розыгрыш / Лотерея
- Раз в неделю — розыгрыш приза (термокружка, пицца, выходной)
- Участие: просто быть активным в чате
- Автоматический выбор победителя
- Публичное объявление в общем чате

### 68. Шкафчик / Ячейка (выдача личных вещей)
- Учёт шкафчиков в раздевалке: кому какой выдано
- Заявка на получение, возврат при увольнении
- Статус: свободен / занят / ремонт

### 69. "Потеряшки" (Lost & Found)
- Кто-то нашёл: ключи, телефон, документы, кошелёк
- Публикует фото + место находки
- Владелец откликается, договаривается о передаче
- История находок и возвратов

### 70. Календарь спортивных событий
- Футбол, волейбол, настольный теннис между цехами
- Расписание, бронь спортзала, состав команд
- Счёт матча, турнирная таблица
- Актуально для тех, кто не участвует — хотя бы следит

## Блок 3 — Уникальные и нестандартные идеи

### 71. "Тайный Санта" (корпоративный)
- В декабре бот случайно распределяет участников: кому дарить подарок
- Анонимно, можно написать пожелания ("люблю чай, не люблю носки")
- Чат для обсуждения: "что дарить?", "как упаковать?"
- Распаковка: фото подарков в общем чате
- Одна из самых тёплых корпоративных традиций

### 72. Трекинг настроения (Mood Tracker)
- Раз в день бот спрашивает: "Как настроение? 😊😐😢"
- Анонимная статистика по отделам
- Руководитель видит динамику: если отдел грустный — пора что-то менять
- Для HR: раннее выявление выгорания
- Психологическая безопасность

### 73. Анонимный вопрос руководителю
- Сотрудник может задать вопрос анонимно (генеральному / начальнику отдела)
- Руководитель отвечает публично в канале "Вопросы и ответы"
- Все видят вопрос (без автора) и ответ
- Снимает страх задавать неудобные вопросы
- Технически: модерация перед публикацией

### 74. Конкурс фото / творчества
- Тема недели: "Мой отпуск ☀️", "Любимый питомец 🐱", "Закат с работы 🌇"
- Загрузка фото через чат, голосование реакциями
- Победитель получает приз
- Артефакты: лучшие фото на главной странице / в столовой на экране

### 75. "Что сегодня на обед?" (меню столовой)
- Утром повар публикует меню на сегодня
- Фото блюд, состав, цена
- Можно заказать / забронировать порцию
- Дизлайк: "Не нравится" — повар видит статистику

### 76. Планерка онлайн (daily standup в чате)
- В 9:00 бот спрашивает: "Что сделал вчера? Что будешь делать сегодня? Есть блокеры?"
- Ответы видны руководителю и команде
- История по дням / сотрудникам
- Не заменяет устную планерку, но для удалёнщиков/смен — идеально

### 77. Книжный клуб / Статьи
- Раз в месяц участники читают одну книгу/статью
- Обсуждение в чате, обмен мнениями
- Библиотека PDF в базе знаний (wiki)
- Выбор следующей книги голосованием

### 78. "Кто меня искал?" (пропущенные упоминания)
- За день кто-то писал `@Имя`, а ты был офлайн
- Утром дайджест: "Вас упоминали 5 раз: @Коля вопрос, @Маша срочно"
- Ссылка на сообщение, сразу перейти
- Никто не теряет важные сообщения

### 79. Свадебный / Детский фонд
- Поздравление от компании: при рождении ребёнка, свадьбе
- Бот отправляет поздравление в общий чат + персонально
- Можно прикрепить PDF-приказ о материальной помощи
- HR заполняет, бот поздравляет

### 80. Поиск напарника / попутчика
- "Кто живёт в районе Автовокзала? Может подвозить по очереди?"
- "Кто сегодня идёт на обед в 13:00?"
- "Ищу партнёра для настольного тенниса в пятницу"
- Канал "Среди своих" — добровольная подписка

### 81. Наставничество (онбординг новых сотрудников)
- Новый сотрудник приходит → бот назначает наставника
- Чат-трек: день 1, день 3, день 7, день 30 — чек-лист ознакомления
- Наставник отмечает "ознакомлен", HR видит прогресс
- Базовые вопросы: "Где туалет?", "Ключи от шкафчика?", "Доступ к 1С?"

### 82. Погода на завтра для производства
- Ежедневный прогноз: температура, ветер, осадки
- Для эстакад, погрузки, наружных работ
- Решение: работать на улице или нет
- Уведомление в 6:00 в чат эстакады/стройки

### 83. Режим "Не беспокоить" (статус для глубокой работы)
- Включается на N часов: "Глубокая работа до 14:00"
- Сообщения приходят, но уведомления не всплывают
- Отправитель видит: "Пользователь в режиме глубокой работы"
- Снимает давление, что нужно ответить мгновенно

### 84. Подпись документа электронной подписью (через чат)
- Сотруднику приходит запрос: "Подпишите документ"
- Открывается PDF, кнопка "Подписать"
- Ставится ЭЦП / простая электронная подпись (PIN-код)
- Юрист/бухгалтер получает подписанный экземпляр

### 85. E-invoicing / Акт выполненных работ
- Внутренний документооборот: акты, счета-фактуры
- Создать → отправить на подпись → подписано → в архив
- Полный цикл внутри чата
- Экспорт в 1С (XML/XLSX)

### 86. Список контактов экстренных служб
- Кнопка "Пожарная 🚒" → номер пожарной части
- "Скорая 🚑" → номер медпункта предприятия
- "Охрана 🚔" → дежурный КПП
- "Дежурный электрик ⚡" → круглосуточный номер
- Доступно из любого чата одной кнопкой

### 87. Доска объявлений (официальная)
- Отдел кадров / администрация публикует: "Собрание в 14:00", "Замена ламп"
- Не теряется в общем чате, висит как канал
- Можно отметить "Прочитал"
- Срок действия: исчезает через N дней

### 88. Программа лояльности (баллы / бонусы)
- За активность, за стаж, за достижения
- Баллы можно потратить: мерч, доп. выходной, место на корпоративной парковке
- Витрина товаров/услуг внутри чата
- Админ управляет балансами

### 89. Квиз / Викторина
- Раз в неделю — 5 вопросов на эрудицию
- Производство: "Какой станок выпускает деталь Х?"
- Общие: "Сколько сотрудников в компании?", "Год основания"
- Рейтинг, приз победителю
- Обучает корпоративной культуре в игровой форме

### 90. "Корпоративный гороскоп"
- Ежедневный шуточный гороскоп для знаков зодиака
- "Скорпионам сегодня повезёт с подписанием договора"
- В пятницу — предсказание на выходные
- Создаёт утренний ритуал зайти в чат

### 91. Онлайн-собрание / вебинар внутри чата
- Не видеозвонок, а текстовая трансляция: докладчик пишет, зрители читают
- Вопросы в отдельный чат, докладчик отвечает
- После — запись (история сообщений)
- Для тех, кто не может присутствовать лично

### 92. Статистика личной активности
- "Сколько сообщений вы отправили за неделю?"
- "Кому вы писали чаще всего?"
- "Ваше любимое время для переписок"
- Личная аналитика — только видит сам пользователь
- Забавно и затягивает

### 93. Напоминание "Выпить воды" / "Размяться"
- Каждый час бот напоминает: "Выпейте воды 💧"
- Раз в 2 часа: "Встаньте, разомните спину"
- Можно отключить в настройках
- Забота о здоровье, особенно для офисных сотрудников

### 94. Список рассылки (аналог e-mail)
- "Уведомить всех начальников отделов"
- "Уведомить всех сотрудников цеха ФФЦ"
- Выбор группы получателей, написать сообщение
- Приходит в личные чаты получателям
- Замена корпоративной рассылке по email

### 95. Детектор токсичных сообщений
- Если сообщение содержит грубость / мат / агрессию → предупреждение
- "Ваше сообщение может быть расценено как неуважительное"
- Рекомендация: переформулировать
- Статистика для HR: кто часто получает предупреждения
- Делает атмосферу в чате культурее

### 96. "Жалоба на сообщение" (модерация)
- Кнопка "Пожаловаться" на любое сообщение
- Анонимно отправляется модератору (HR / СБ)
- Модератор: скрыть / вынести предупреждение / забанить
- Система предупреждений: 3 страйка → временная блокировка

### 97. Бейджи в чате (роли / статусы)
- Возле имени: 🛡️ СБ, ⚙️ Инженер, 🩺 Врач, 📋 Кадры, 💼 Директор, 🔧 IT
- Автоматически или назначается админом
- Визуально понятно, кто перед тобой
- В крупной компании: не знаешь всех в лицо, но видишь роль

### 98. "Курить? Перекур!" (учёт перекуров)
- Кнопка: "Я на перекур 🚬"
- Таймер: "Вы курите уже 15 минут..."
- Шуточная статистика: "Вы провели 40 часов в курилке в этом месяце"
- Можно добавить элемент соревнования: меньше всех курит — приз
- На самом деле — вовлекает курильщиков в чат

### 99. Фотозона / Мемы дня
- Лучшие фото с корпоративов, смешные моменты
- Мемы про работу (актуальные шаблоны)
- Кнопка "Создать мем" — наложить текст на шаблон
- Доска смеха: поднимает настроение

### 100. Идея дня от сотрудников
- Каждый день новый сотрудник публикует идею: "Как улучшить нашу работу"
- Очередь составляется автоматически
- Все комментируют, ставят реакции
- Лучшие идеи попадают руководству
- Сотрудник чувствует себя услышанным
