Презентация проекта Chat App

Корпоративный мессенджер — современное веб-приложение для обмена сообщениями и файлами в реальном времени, разработанное с учётом потребностей бизнеса. Приложение объединяет функциональность личного общения, командной работы и корпоративных инструментов в единой платформе.

🎯 Целевая аудитория

Команды разработчиков

  • Быстрая коммуникация в чатах
  • Обмен кодом и файлами с превью изображений
  • Создание задач для совместной работы

HR-отделы

  • Управление задачами и бронирование переговорных
  • Отслеживание отпусков и больничных
  • Телефонная книга сотрудников

Менеджеры проектов

  • Координация задач через календарь
  • Общие чаты для команд
  • Планирование встреч и напоминания

Все сотрудники

  • Общение в личных и групповых чатах
  • Поиск информации в базе знаний Wiki
  • Уведомления о важных сообщениях

✨ Ключевые возможности

1. Чат-система

  • Личные чаты — общение один на один
  • Групповые чаты — создание с несколькими участниками
  • Общий чат — доступен всем пользователям компании
  • Реакции на сообщения (эмодзи)
  • Превью изображений и файлов

2. База знаний Wiki

  • Категории статей с возможностью создания новых
  • Редактирование статей (с правами доступа)
  • Уровни доступа: публичные, приватные, доступ по выбору пользователей
  • Поиск по статьям и файлам

3. Задачи и календарь

  • Создание задач с описанием, сроком, временем выполнения
  • Цветовое кодирование задач
  • Напоминания о задачах
  • Просмотр задач на день/неделю/месяц

4. Переговорные комнаты

  • Бронирование переговорных комнат
  • Просмотр расписания встреч
  • Управление правами на бронирование (администраторы)

5. Телефонная книга

  • Список сотрудников с контактами
  • Мобильный и рабочий телефон, email
  • Статус онлайн/оффлайн
  • Поиск по имени или телефону

6. HR-инструменты

  • Заявки на отпуск (vacation), больничный (sick), выходной (day_off)
  • Просмотр заявок: свои и pending
  • Уведомления о заявках

7. Бот-помощник

  • /чат — создание чата
  • /задача — управление задачами
  • /календарь — просмотр расписания
  • /переговорка — бронирование комнаты
  • /файлы — загрузка файлов
  • /статус — проверка онлайн-статуса
  • /сегодня — задачи, дни рождения, встречи

8. Управление устройствами

  • Поддержка входа с нескольких устройств
  • Просмотр активных сессий
  • Возможность завершить чужую сессию
  • Сохранение истории сообщений между устройствами

🚀 Преимущества проекта

Всё в одном — не нужно переключаться между мессенджером, Trello/Jira, Google Calendar и Wiki
Бесплатно и самохостинг — работает на вашем сервере, данные остаются у вас
Легкий старт — один файл server.js, база данных создаётся автоматически
Масштабируемо — SQLite WAL mode + асинхронный логгер для производительности
Адаптивный дизайн — работает на мобильных устройствах и десктопах
Безопасность — шифрование, управление сессиями, права доступа

📁 Структура проекта

chat-app/
├── backend/          # Сервер (Node.js + Express + Socket.IO)
│   ├── server.js     # Основной файл сервера (~700 строк)
│   ├── bot/          # Бот-помощник
│   │   ├── engine.js # Движок бота, команды
│   │   └── commands.js # Обработчики команд (задачи, контакты и т.д.)
│   ├── backups/      # Резервные копии базы данных
│   └── uploads/      # Загруженные файлы
├── frontend/         # Клиент (React)
│   ├── src/
│   │   ├── App.js    # Главный компонент (~1200 строк)
│   │   ├── ChatWindow.jsx  # Окно чата
│   │   ├── CalendarTasks.jsx  # Задачи и календарь
│   │   ├── SettingsView.jsx  # Настройки
│   │   └── css/      # Стили (glassmorphism)
│   └── build/        # Сборка React приложения
├── electron/         # Ресурсы для Electron
│   └── icon.ico      # Иконка приложения
├── uploads/          # Общие файлы
└── README.md         # Документация проекта
