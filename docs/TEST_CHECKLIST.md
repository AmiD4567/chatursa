## Диагностика проблем

### Сервер не запускается
```bash
# Проверить порт
netstat -ano | findstr :3001

# Проверить логи
type c:\ChatServer\chat-app\backend\server-runtime.log
```

### WebSocket не подключается
1. Проверить CORS настройки
2. Проверить firewall
3. Проверить логи браузера (F12)

### БД не сохраняется
1. Проверить права на папку
2. Проверить место на диске
3. Проверить `debouncedSaveDatabase` вызовы
