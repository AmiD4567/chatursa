## 🚀 Как запустить проект

### Вариант 1: Ручной запуск (для разработки)

```bash
# Terminal 1 - Backend
cd c:\ChatServer\chat-app\backend
node server.js

# Terminal 2 - Frontend
cd c:\ChatServer\chat-app
npm start
```

### Вариант 2: Автоматический перезапуск (рекомендуется)

```bash
# Запустите в отдельном окне
c:\ChatServer\run-server-auto.bat

# Затем frontend
cd c:\ChatServer\chat-app
npm start
```

### Вариант 3: Production сборка

```bash
cd c:\ChatServer\chat-app
npm run electron:build
```
