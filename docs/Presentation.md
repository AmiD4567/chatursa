# Презентация проекта Chat App

## О проекте

**Корпоративный мессенджер** — современное веб-приложение для обмена сообщениями и файлами в реальном времени, разработанное с учётом потребностей бизнеса. Приложение объединяет функциональность личного общения, командной работы и корпоративных инструментов в единой платформе.

---

## 🎯 Целевая аудитория и потребности

### Кто будет использовать приложение:
- **Команды разработчиков** — быстрая коммуникация, обмен кодом и файлами
- **HR-отделы** — управление задачами, бронирование переговорных, отслеживание отпусков
- **Менеджеры проектов** — координация задач, календарь встреч, общие чаты
- **Все сотрудники компании** — общение, поиск информации в базе знаний

### Какие потребности закрывает проект:

| Потребность | Решение |
|-------------|---------|
| Быстрая коммуникация внутри команды | Личные и групповые чаты с уведомлениями |
| Обмен файлами и документами | Загрузка файлов с превью изображений |
| Отслеживание задач и сроков | Календарь задач, напоминания, общие задачи |
| Планирование встреч | Бронирование переговорных комнат |
| Поиск информации | База знаний (Wiki) с категориями и доступом по уровням |
| Управление персоналом | Телефонная книга, HR-заявки (отпуска, больничные) |
| Безопасность данных | Шифрование сообщений, управление устройствами |

## ✨ Ключевые возможности приложения

### 1. Чат-система
- **Личные чаты** — общение один на один
- **Групповые чаты** — создание чатов с несколькими участниками
- **Общий чат** — доступен всем пользователям компании
- Реакции на сообщения (эмодзи)
- Превью изображений и файлов
- Уведомления о новых сообщениях

### 2. Пользовательский профиль
- Аватарка, имя, email, телефонные номера
- Статус пользователя (онлайн/оффлайн)
- Возможность редактирования профиля
- Управление настройками приложения

### 3. База знаний (Wiki)
- Категории статей с возможностью создания новых
- Редактирование статей (с правами доступа)
- Уровни доступа: публичные, приватные, доступ по выбору пользователей
- Поиск по статьям и файлам
- Поддержка вложений к статьям

### 4. Задачи и календарь
- Создание задач с описанием, сроком, временем выполнения
- Цветовое кодирование задач
- Напоминания о задачах
- Просмотр задач на день/неделю/месяц
- Общие задачи (поделиться задачей с другими пользователями)

### 5. Переговорные комнаты
- Бронирование переговорных комнат
- Просмотр расписания встреч
- Управление правами на бронирование (администраторы)

### 6. Телефонная книга
- Список сотрудников с контактами
- Мобильный и рабочий телефон, email
- Статус онлайн/оффлайн
- Поиск по имени или телефону

### 7. HR-инструменты
- Заявки на отпуск (vacation), больничный (sick), выходной (day_off)
- Просмотр заявок: свои и pending
- Уведомления о заявках

### 8. Опросы (Polls)
- Создание анонимных или открытых опросов
- Возможность множественного выбора ответов
- Таймер закрытия опроса
- Скрытие результатов до окончания

### 9. Объявления (Announcements)
- Публикация важных сообщений для всех пользователей
- Приоритеты: normal, high, emergency
- Отслеживание прочтения

### 10. Уведомления
- Браузерные push-уведомления о новых сообщениях
- Внутренние уведомления (дни рождения, задачи)
- Настройки уведомлений (звук, от бота и т.д.)

### 11. Бот-помощник
- Команды для быстрого доступа к функциям:
  - `/чат` — создание чата
  - `/задача` — управление задачами
  - `/календарь` — просмотр расписания
  - `/переговорка` — бронирование комнаты
  - `/файлы` — загрузка файлов
  - `/статус` — проверка онлайн-статуса
  - `/профиль` — редактирование профиля
  - `/уведомления` — список уведомлений
  - `/сегодня` — задачи, дни рождения, встречи на сегодня
  - `/контакты` — телефонная книга
  - `/онбординг` — обучение нового пользователя
  - `/поиск`, `/вики` — поиск в базе знаний
- Кнопки быстрого доступа

### 12. Управление устройствами (Multi-device)
- Поддержка входа с нескольких устройств
- Просмотр активных сессий
- Возможность завершить чужую сессию
- Сохранение истории сообщений между устройствами

### 13. Конфиденциальность и безопасность
- Шифрование сообщений (AES-256-CBC)
- Энд-ту-энд шифрование для групповых чатов
- Самоуничтожающиеся сообщения с таймером
- Управление правами администратора

### 14. Настройки приложения
- Выбор темы (светлая/тёмная)
- Размер текста
- Фоновые изображения для чата
- Автозапуск при старте ОС

## 🛠️ Технологии и архитектура

### Backend:
| Технология | Описание |
|------------|----------|
| Node.js | Асинхронный JavaScript runtime |
| Express | Веб-фреймворк для REST API |
| Socket.IO | Реальное время (WebSockets) |
| better-sqlite3 | SQLite база данных (сynchronous, WAL mode) |
| Multer | Обработка загрузки файлов |
| bcryptjs | Хэширование паролей |
| web-push | Push-уведомления для браузеров |
| firebase-admin | Firebase Cloud Messaging (FCM) |

### Frontend:
| Технология | Описание |
|------------|----------|
| React | Библиотека UI компонентов |
| Socket.IO Client | Подключение к WebSocket серверу |
| marked | Парсинг Markdown в Wiki |
| DOMPurify | Очистка HTML от XSS-атак |

### База данных (SQLite):
```
users, chats, chat_participants, messages, message_reactions,
unread_messages, user_sessions, security_logs, ui_settings,
push_subscriptions, hr_requests, meeting_room_bookings,
task_shares, calendar_tasks, wiki_articles, polls, announcements,
user_device_sessions, sticker_uploads, emoji_uploads,
chat_documents, chat_files, e2ee_keys, group_e2ee_keys
```

### Electron (Desktop приложение):
- Пакетирование frontend + backend в нативное Windows-приложение
- Автообновления через GitHub Releases
- Создание ярлыков на рабочем столе и в меню "Пуск"

## 🚀 Преимущества проекта

1. **Всё в одном** — не нужно переключаться между мессенджером, Trello/Jira, Google Calendar и Wiki
2. **Бесплатно и самохостинг** — работает на вашем сервере, данные остаются у вас
3. **Легкий старт** — один файл `server.js`, база данных создаётся автоматически
4. **Масштабируемо** — SQLite WAL mode + асинхронный логгер для производительности
5. **Адаптивный дизайн** — работает на мобильных устройствах и десктопах
6. **Безопасность** — шифрование, управление сессиями, права доступа

## 📁 Структура проекта

```
chat-app/
├── backend/          # Сервер (Node.js + Express + Socket.IO)
│   ├── server.js     # Основной файл сервера (~700 строк)
│   ├── bot/          # Бот-помощник
│   │   ├── engine.js # Движок бота, команды
│   │   └── commands.js # Обработчики команд (задачи, контакты и т.д.)
│   ├── backups/      # Резервные копии базы данных
│   └── uploads/      # Загруженные файлы
├── frontend/         # Клиент (React)
│   ├── src/
│   │   ├── App.js    # Главный компонент (~1200 строк)
│   │   ├── ChatWindow.jsx  # Окно чата
│   │   ├── CalendarTasks.jsx  # Задачи и календарь
│   │   ├── SettingsView.jsx  # Настройки
│   │   └── css/      # Стили (glassmorphism)
│   └── build/        # Сборка React приложения
├── electron/         # Ресурсы для Electron
│   └── icon.ico      # Иконка приложения
├── uploads/          # Общие файлы
└── README.md         # Документация проекта
```

## 📝 Заключение

**Chat App** — это готовое решение для корпоративной коммуникации, которое закрывает большинство потребностей команды: от быстрого обмена сообщениями до планирования задач и управления персоналом. Приложение легко развернуть на любом сервере с Node.js, не требует сложной настройки и предоставляет богатый функционал "из коробки".
