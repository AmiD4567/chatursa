## 1. Подготовка

### 1.1 Проверка текущей версии
Откройте файл `chat-app/package.json` и проверьте версию:
```json
"version": "1.0.55"
```

### 1.2 Определение следующей версии
Следующая версия должна быть выше предыдущей. Например:
- Если последняя версия была `1.0.54`, следующая будет `1.0.55`
- Формат: `MAJOR.MINOR.PATCH` (например, `1.0.56`)

### 1.3 Обновление версии в package.json
Откройте `chat-app/package.json` и измените версию:
```json
{
  "name": "chat-app",
  "version": "1.0.56",  // ← Измените на новую версию
  ...
}
```

### 1.4 Обновление CHANGELOG.md (рекомендуется)
Откройте `chat-app/CHANGELOG.md` и добавьте новый раздел:
```markdown
## v1.0.56 - 2026-05-04

### 🐛 Исправления:
- [Ваше исправление]

### ✨ Добавлено:
- [Новая функция]
```

## 2. Получение GitHub Token

### 2.1 Создание Personal Access Token (PAT)

1. Зайдите на https://github.com
2. Нажмите на ваш аватар в правом верхнем углу → **Settings**
3. В левой панели выберите **Developer settings** → **Personal access tokens** → **Tokens (classic)**
4. Нажмите кнопку **Generate new token (classic)**
5. Заполните форму:
   - **Note**: `ChatAppRelease-{дата}` (например, `ChatAppRelease-2026-05-04`)
   - **Expiration**: Выберите срок действия токена (рекомендуется 1 год или меньше)
   - **Select scopes**: Отметьте галочку:
     - ✅ `public_repo` (для публичных репозиториев)
     - Или `repo` (для приватных репозиториев)

6. Нажмите **Generate token**
7. **СКОПИРУЙТЕ ТОКЕН** — он показывается только один раз! Он начинается с `ghp_...`

### 2.2 Сохранение токена

Сохраните токен в надёжном месте (менеджер паролей, зашифрованный файл).

## 4. Публикация релиза через командную строку

### 4.1 Настройка GitHub Token

#### ⚡ Предпочтительный метод (использование готового токена):

**PowerShell:**
```powershell
$env:GH_TOKEN="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"
```

**CMD:**
```cmd
set GH_TOKEN=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
```

После установки переменной запустите публикацию:
```powershell
cd chat-app
npm run release
```

#### 📝 Создание нового токена (если потребуется):

1. Зайдите на https://github.com/settings/tokens
2. Нажмите **Generate new token (classic)**
3. Заполните форму:
   - **Note**: `ChatAppRelease-{дата}` (например, `ChatAppRelease-2026-05-04`)
   - **Expiration**: Выберите срок действия токена (рекомендуется 1 год или меньше)
   - **Select scopes**: Отметьте галочку:
     - ✅ `public_repo` (для публичных репозиториев)
     - Или `repo` (для приватных репозиториев)
4. Нажмите **Generate token**
5. **СКОПИРУЙТЕ ТОКЕН** — он показывается только один раз! Он начинается с `ghp_...`


### 4.2 Запуск публикации
```powershell
cd chat-app
npm run release
```

Это выполнит:
1. ✅ Сборку фронтенда (`npm run build`)
2. ✅ Создание NSIS установщика Windows
3. ✅ Автоматическую публикацию релиза на GitHub с тегом `v{VERSION}`
4. ✅ Создание файла `latest.yml` для проверки версий

### 4.3 Альтернативная команда
```powershell
electron-builder --win nsis --publish always
```

## 5. Ручная публикация через веб-интерфейс GitHub

Если автоматическая публикация не сработала, можно сделать это вручную:

### 5.1 Создание тега в Git
```powershell
cd chat-app
git tag v1.0.56
git push origin v1.0.56
```

### 5.2 Создание релиза через веб-интерфейс

1. Зайдите на https://github.com/AmiD4567/chatursa/releases
2. Нажмите **Draft a new release**
3. Заполните поля:
   - **Tag version**: `v1.0.56`
   - **Release title**: `Release 1.0.56`
   - **Description**: Добавьте описание изменений (можно скопировать из CHANGELOG.md)
4. Нажмите **Attach release asset** и выберите файл `Chat App-Setup-1.0.56.exe`
5. Нажмите **Publish release**

## 🔧 Решение проблем

### Проблема: "Validation Failed" при публикации
**Причина**: Токен не имеет нужных прав или истёк срок действия.

**Решение**:
1. Проверьте, что токен начинается с `ghp_`
2. Убедитесь, что выбран scope `public_repo` или `repo`
3. Создайте новый токен и повторите публикацию

### Проблема: Файл не загружается
**Причина**: Сбой при загрузке файла на GitHub.

**Решение**:
1. Используйте ручную публикацию через веб-интерфейс (раздел 5)
2. Или попробуйте команду без `--publish`:
   ```powershell
   electron-builder --win nsis
   ```
   Затем вручную загрузите файл через GitHub UI

### Проблема: "Repository not found"
**Причина**: Неправильные owner/repo в конфигурации.

**Решение**:
Проверьте `chat-app/package.json`:
```json
"publish": {
  "provider": "github",
  "owner": "AmiD4567",
  "repo": "chatursa"
}
```
